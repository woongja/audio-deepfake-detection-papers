## 문제 정의

TTS(Text-to-Speech) 모델은 텍스트를 입력받아 음성을 생성하는 과정에서 본래 음성에 내재된 리듬 정보를 정확하게 반영하지 못하고, 인공적인 리듬 아티팩트를 발생시킬 수 있다. 이러한 TTS 생성 음성은 기존 스포오핑 음성 검출 시스템의 취약점을 드러내며, 검출 시스템의 신뢰성에 대한 문제를 야기한다. 따라서 TTS 생성 음성에 특화된 리듬 정보를 활용한 스포오핑 음성 검출 시스템의 필요성이 제기된다.

## 제안 방법

본 논문에서는 TTS 생성 음성의 리듬 정보를 활용하여 스포오핑 음성 검출 시스템을 강화하기 위해 rhythm perturbation module을 제안한다. 이 모듈은 copy-synthesis 데이터 증강 방법의 단점을 보완하며, 생성된 가짜 음성에 다양한 리듬 정보를 부여하여 검출 모델이 리듬 정보의 아티팩트에 집중하도록 유도한다. 구체적으로, vocal tract response를 제거하여 얻은 glotthal flow를 활용하고, 이를 반복적 적응적 역필터링(Iterative Adaptive Inverse Filtering, IAIF) 방법을 통해 추출한다.
