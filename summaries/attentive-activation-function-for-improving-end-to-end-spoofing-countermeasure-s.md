## 제안 방법

본 논문에서는 end-to-end 스포이핑 대책 시스템에 Attention Rectified Linear Unit (AReLU) 활성화 함수를 적용하는 방법을 제안합니다. AReLU는 관련 입력 특징의 기여도를 높이고 부적절한 특징을 억제하는 메커니즘을 통해 스포이핑 공격으로 생성된 특징에 집중할 수 있도록 돕습니다. 제안하는 프레임워크는 ResNet 기반의 end-to-end 시스템으로 구성되며, ResNet의 각 Residual Block 이후에 attention pooling layer를 추가하여 시간적 정보를 통합하고, 최종적으로 bona fide 및 스포이핑 클래스를 분류하는 fully-connected layer와 softmax layer를 사용합니다.
