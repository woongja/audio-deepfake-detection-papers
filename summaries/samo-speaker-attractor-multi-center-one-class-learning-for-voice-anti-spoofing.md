**Evaluation metrics.** 성능 평가 지표로는 Equal Error Rate (EER)와 minimum tandem detection cost (min t-DCF)을 사용했습니다. EER은 특정 임계값에서 false acceptance rate과 false rejection rate의 동일한 지점의 비율을 나타냅니다. min t-DCF는 ASV 시스템에 CM 시스템을 통합했을 때 발생하는 모든 유형의 오류를 평가하는 지표입니다.

**Comparison methods.** SAMO는 AASIST와 OC-Softmax 두 가지 state-of-the-art anti-spoofing 방법과 비교되었습니다. AASIST는 그래프 신경망 기반 모델이며, OC-Softmax는 ResNet-18 기반 모델에 일 클래스 학습 손실 함수를 적용한 것입니다.
