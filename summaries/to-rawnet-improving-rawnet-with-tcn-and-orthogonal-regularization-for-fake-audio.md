## 문제 정의

기존의 딥페이크 음성 검출 방법은 사람이 직접 설계한 특징(hand-crafted features)에 의존하며, 이는 음성 신호의 중요한 정보를 손실시킬 수 있다. 최근에는 raw waveform을 직접 입력으로 사용하는 방법들이 등장했지만, RawNet과 같은 기존 방법들은 SiNC-conv 필터의 파라미터 최적화를 충분히 고려하지 않아 성능에 한계가 있었다.

## 제안 방법

본 논문에서는 RawNet 모델의 SiNC-conv 레이어에 orthogonal convolution과 temporal convolutional network (TCN)을 결합한 TO-RawNet 모델을 제안한다. orthogonal convolution은 SiNC-conv 필터 간의 상관관계를 줄여 특징 표현 능력과 클래스 내 특징 표현을 향상시키고, TCN은 음성 신호의 장기적인 의존성을 포착하여 모델의 성능을 개선한다.

## 실험·결과

ASVspoof 2019 데이터셋에 대한 실험 결과, 제안하는 TO-RawNet 시스템은 논문에서 비교된 다른 시스템에 비해 논리적 접근 시나리오에서 EER을 66.09% 감소시키는 것으로 나타났다. 또한, orthogonal regularization과 TCN을 모두 적용한 TO-RawNet-M 모델이 다른 구성 요소들을 제거한 모델들보다 더 나은 성능을 보였으며, SOTA 시스템인 AASIST에 적용했을 때도 성능 향상이 확인되었다.
