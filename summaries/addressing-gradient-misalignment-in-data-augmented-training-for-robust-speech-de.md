## 제안 방법

본 논문에서는 데이터 증강된 입력과 원본 입력을 병렬로 처리하는 dual-path data-augmented (DPDA) training framework를 제안합니다. 각 학습 발화는 원본 입력 경로와 증강된 입력 경로를 통해 모델에 입력되며, 두 경로에서 계산된 backpropagation gradient를 비교하여 충돌이 발생할 경우 gradient alignment 방법을 적용합니다. 본 연구에서는 PCGrad라는 gradient alignment 방법을 사용합니다.
