## 문제 정의

자동 화자 확인(ASV) 시스템에서 조작된 오디오(spoofed audio) 탐지는 정보 보안 및 사기 방지에 매우 중요하다. 하지만 새로운 조작 기법이 등장함에 따라, 기존의 조작 오디오 탐지 방법은 알려진 조작 방식에만 국한되는 경향이 있으며, 새로운 유형의 조작에 대한 일반화 능력이 부족하다. 따라서 실제 오디오 특징을 더 잘 모델링하고, 알려지지 않은 조작 방식에도 효과적으로 대응할 수 있는 강력한 조작 오디오 탐지 방법이 필요하다.

## 제안 방법

본 논문에서는 실제 오디오 특징 학습에 집중하여 조작 오디오 탐지 성능을 향상시키는 Genuine-Focused Learning (GFL) 프레임워크를 제안한다. GFL-FAD는 Mask AutoEncoder (MAE)를 기반으로 하며, 실제 오디오 특징을 효과적으로 추출하고 조작 오디오의 영향을 줄이기 위해 다음과 같은 핵심 구성 요소를 포함한다.

* **Countefractual Reasoning Enhanced Representation (CRER):** MAE 디코더를 통해 실제 오디오 재구성을 수행하여 실제 오디오 특징을 효과적으로 모델링한다.
* **Genuine Audio Reconstruction Loss (GAR Loss):** 학습 과정에서 실제 오디오 특징 학습에 집중하도록 하여 모델의 일반화 성능을 향상시킨다.
* **Content-related Bottleneck (BN) Features:** MAE에서 추출된 내용 관련 특징을 활용하여 실제 오디오에 대한 지식을 보강하고 모델의 견고성을 높인다.
* **Attention Mechanism:** BN 특징과 CERR를 효과적으로 융합하여 최종 분류 성능을 향상시킨다.
