## 문제 정의

기존의 음성 디페이크 탐지 방법은 실제 음성과 디페이크 음성을 이진 분류 문제로 다루는 경우가 많으나, 알려진 디페이크 공격에 과적합될 가능성이 있으며 새로운 공격에 대한 탐지 능력이 떨어집니다. 한편, 단일 센트로이드 기반의 one-class learning은 실제 음성 분포를 단일 공간으로 단순화하여 실제 음성의 다양성을 간과할 수 있으며, 음성 품질과 같은 중요한 정보를 활용하지 못하는 단점이 있습니다.

## 제안 방법

본 논문에서는 이러한 문제점을 해결하기 위해 품질 인식 멀티-센트로이드 one-class learning(QAMO) 프레임워크를 제안합니다. QAMO는 실제 음성 분포를 단일 센트로이드가 아닌 여러 개의 품질 인식 센트로이드로 모델링합니다. 각 센트로이드는 특정 품질 수준의 음성을 대표하며, 품질 수준은 MOS(Mean Opinion Score)를 기반으로 분류됩니다. 학습 시에는 각 센트로이드가 해당 품질 수준의 음성에 적합하도록 품질 기반 분류 손실을 사용하며, 예측 시에는 모든 센트로이드 간의 유사도를 평균하는 앙상블 스코어링 전략을 적용합니다.
