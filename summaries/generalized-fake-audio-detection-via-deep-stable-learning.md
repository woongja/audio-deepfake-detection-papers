## 문제 정의

기존의 FAD 모델은 특정 데이터 분포에서 높은 성능을 보이지만, 학습 데이터와 다른 분포의 테스트 데이터에서는 성능이 저하되는 문제(distribution shift)를 겪습니다. 이는 새로운 합성 기술이나 통신 환경 변화 등으로 인해 발생하며, 기존의 방법들은 추가 데이터 확보나 복잡한 학습 과정 요구 등의 단점을 가집니다.

## 제안 방법

본 논문에서는 distribution shift 문제를 해결하기 위해 Sample Weight Learning (SWL) 모듈을 제안합니다. SWL 모듈은 입력 특징들을 decorrelate하여 모델이 다양한 환경에서도 안정적인 예측을 할 수 있도록 돕습니다. 특히, Random Fourier Features (RFF)를 사용하여 특징 간의 상관관계를 제거하고, 반복적인 최적화를 통해 글로벌 샘플 가중치를 학습합니다. 이 모듈은 기존 FAD 모델에 쉽게 통합될 수 있으며, 추론 과정에 영향을 주지 않습니다.

## 실험·결과

본 논문에서는 AASIST, AASIST-L, RawNet2, TSSD 모델에 SWL 모듈을 적용하여 AVSspoof 2019 LA, 2021 LA, 2021 DF 데이터셋에서 실험을 진행했습니다. 실험 결과, SWL을 적용한 AASIST 모델은 EER이 1.38%로 개선되었고, AASIST-L 모델은 1.14%로 개선되는 등 전반적으로 성능 향상을 보였습니다. 특히, AASIST-L 모델의 경우 RFF 매핑 함수 개수가 많을수록, 스펙트럴 특징 관련 노드 특징 조합이 좋을수록 성능 향상이 두드러졌습니다.
