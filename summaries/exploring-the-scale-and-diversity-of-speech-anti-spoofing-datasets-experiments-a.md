## 2.1 Fake Speech Detection

스푸핑 음성 탐지는 생성된 음성을 실제 음성과 구별하는 것을 목표로 합니다. 초기 연구는 두 음성 간의 차이점을 포착하는 판별적 특징을 설계하는 데 중점을 두었습니다. 스펙트럴 계수는 광범위한 연구에서 사용되었으며, F0 서브밴드 정보, 감정 관련 특징, 호흡-침묵 상관 관계 등 다른 음성 속성도 스푸핑 신호를 밝히는 데 활용되었습니다. 또한, RawNet2, RawGAT, AASIST와 같은 대표적인 연구에서는 손으로 설계된 특징 없이 원시 파형에서 직접 표현을 학습하는 end-to-end 방법을 사용했습니다.

최근에는 Wav2Vec, HuBERT, WavLM과 같은 자기 지도 학습(SSL) 모델이 스피치 앤티-스푸핑 분야에서 두각을 나타내고 있으며, 일반적으로 사전 훈련된 특징 추출기를 다운스트림 분류기와 결합하는 방식으로 사용됩니다. 예를 들어, Wav2Vec-AASIST는 AASIST의 sinc 레이어를 Wav2Vec 프런트엔드로 대체하고, Multi_SSL은 다중 게이트 컨볼루션을 백엔드 분류기로 사용하여 지역 및 전역 음성 아티팩트를 모두 포착합니다. 지금까지의 연구 결과에 따르면, 사전 훈련된 자기 지도 학습 표현은 일반화 성능을 크게 향상시키는 것으로 입증되었습니다.

## 2.2 Speech Anti-spoofing Datasets

지난 10년간 스피치 생성 기술의 품질과 다양성이 발전함에 따라, 일반화 성능을 높이기 위한 새로운 데이터셋을 지속적으로 도입하는 추세입니다. 초기 진전은 주로 ASVspoof 시리즈와 같은 공개 챌린지에 의해 주도되었으며, 논리적 및 물리적 접근 공격부터 딥페이크까지 다양한 벤치마크를 제공했습니다. AVSspoof 시리즈 외에도 FMFCC-A와 ADD 챌린지는 만다린 데이터셋의 부족을 해소하는 데 기여했습니다.

이러한 일반적인 벤치마크 외에도, 특정 목표를 달성하기 위한 다양한 작업별 데이터셋이 제안되었습니다. 확산 모델로 생성된 음성을 탐지하기 위해 DiffSSD 및 Diffuse or Confuse가 도입되었으며, CodecFake 및 Codecfake는 신경 코덱 모델을 사용하여 생성된 가짜 오디오를 생성합니다. FamousFigures 및 ZH-FamousFigures는 유명인 사칭 공격을 목표로 하며, FSW는 실제 소셜 미디어 플랫폼에서 실제 및 가짜 음성을 모두 수집합니다. 또한, In-the-Wild, RTCFake 및 VoiceWuKong과 같은 데이터셋은 실제 배포 환경에서 모델의 견고성과 일반화 성능을 평가하도록 설계되었습니다.

최근에는 스피치 앤티-스푸핑 데이터셋이 더 큰 규모와 더 높은 다양성을 갖도록 발전하고 있습니다. MLAAD는 40개 언어와 119,000시간의 데이터를 포함하며, CD-ADD는 5개 생성 방법을 포함하는 88,224시간의 데이터를 제공합니다. AVSspoof5는 8개 생성 방법을 포함하는 163,560시간의 데이터를 제공합니다.

## 3 Experimental Setups

본 연구에서는 스피치 앤티-스푸핑 모델의 일반화 성능에 미치는 훈련 데이터 크기와 다양성의 영향을 분석하기 위해 여러 훈련 세트를 변경하는 실험을 설계했습니다. 스피치 생성 방법이 고정된 상태에서 훈련 데이터 크기를 변경하고, 여러 스피치 앤티-스푸핑 데이터셋에서 샘플을 추출하여 복합 훈련 세트를 구성하여 데이터 다양성을 변경했습니다.

**훈련 세트:**
* **ASVspoof5:** 8가지 스피치 생성 방법을 포함하는 163,560시간의 데이터셋입니다.
* **Speechfake-BD:** 30가지 스피치 생성 방법을 포함하는 1,163시간의 데이터셋입니다.
* **CD-ADD:** 5가지 스피치 생성 방법을 포함하는 88,224시간의 데이터셋입니다.
* **SpoofCeleb:** 10가지 스피치 생성 방법을 포함하는 1982시간의 데이터셋입니다.

**데이터 크기 변화:**
* 훈련 데이터 크기를 1%, 5%, 10%, 20%, 50%, 100%로 조절하여 실험을 수행했습니다.
* 각 데이터 크기 설정에 대해 동일한 스피치 생성 방법에서 샘플을 추출하여 훈련했습니다.

**데이터 다양성 변화:**
* 여러 스피치 앤티-스푸핑 데이터셋에서 샘플을 추출하여 복합 훈련 세트를 구성했습니다.
* 복합 훈련 세트는 63,000개의 샘플과 53개의 스피치 생성 방법을 포함합니다.

## 4 Results and Analysis

본 연구에서는 다양한 훈련 세트와 테스트 세트를 사용하여 훈련 데이터 크기와 다양성이 스피치 앤티-스푸핑 모델의 일반화 성능에 미치는 영향을 분석했습니다. 모델 성능은 Equal Error Rate (EER) 메트릭을 사용하여 평가했습니다.

**결론 1:** 훈련 데이터 크기를 늘리는 것만으로는 모델 성능이 반드시 향상되지 않습니다. 오히려 과적합을 유발하여 다른 도메인으로의 일반화 성능을 저해할 수 있습니다. Speechfake 훈련 세트에서 50%의 데이터 크기를 사용한 모델은 20%의 데이터 크기를 사용한 모델과 거의 동일한 성능을 보였으며, 100%의 데이터 크기를 사용한 모델은 성능이 저하되는 경향을 보였습니다.
