## 문제 정의

음성 생성 기술의 발전으로 인해 음성 위조(DF)의 위협이 증가하고 있으며, 이를 효과적으로 탐지하는 기술의 중요성이 커지고 있다. 기존의 음성 위조 탐지 방법은 주로 음성 신호의 특징을 추출하여 분석하는 방식에 집중해 왔으나, 실제 환경 데이터셋에서의 성능은 여전히 개선의 여지가 있다.

## 제안 방법

본 연구에서는 state-of-the-art 자동 음성 인식(ASR) 모델인 Whisper의 encoder를 음성 위조 탐지의 전처리 단계로 활용하는 방법을 제안한다. Whisper 모델이 학습한 방대한 양의 데이터를 통해 얻어진 특징들은 음성 신호의 본질적인 특성을 효과적으로 포착하며, 특히 인공적으로 변조된 음성 샘플을 식별하는 데 유리할 것으로 예상된다.
